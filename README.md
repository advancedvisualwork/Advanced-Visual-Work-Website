# 🌐 Advanced Visual Work — Website Oficial

Repositório do site institucional oficial da **Advanced Visual Work (AVW)**. Uma landing page de alta performance, minimalista e responsiva, projetada para apresentar os serviços de criação e hospedagem de sites para empresas e comércios.

## 🚀 Sobre o Projeto

O site da **AVW** foi construído com foco em **velocidade, acessibilidade e elegância visual**. Ele apresenta os pilares da empresa, portfólio interativo por segmento e canais diretos de contato comercial.

### ✨ Principais Funcionalidades

* **Smart CTA Email:** Lógica em JavaScript que redireciona automaticamente para o app de e-mail padrão ou aciona a interface de composição do Gmail em desktops.
* **Cópia Rápida com Feedback:** Funcionalidade de um clique para copiar o e-mail oficial para a área de transferência com fallback.
* **Design Responsivo & Mobile Bar:** Navegação adaptada para dispositivos móveis com barra fixa inferior de contato rápido.
* **Performance & Animações Fluidas:** Uso de CSS puro com variáveis, animações personalizadas (`clip-path` e `keyframes`) e tipografia moderna via Google Fonts (*Big Shoulders Display* e *Geist*).

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica e acessível (`aria-*` tags, seções bem definidas).
* **CSS3 Moderno:** Design minimalista, variáveis CSS, Grid Layout, Flexbox e `backdrop-filter`.
* **JavaScript (Vanilla ES6):** Manipulação de DOM leve, eventos de navegação e tratamento de interações sem dependências externas.
